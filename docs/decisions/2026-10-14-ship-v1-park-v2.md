# Ship v1 (gridmaster-react), park v2

Date: 2026-10-14. Status: accepted.

## What was found

- The working tree was a half-finished restructure. The v1 source lived under `legacy/v1/` with no manifest, tsconfig or vite config; the root was an npm-workspace scaffold for v2 (`packages/core`, `packages/react`, `apps/playground`) holding config files only.
- The v2 source (core, react, playground; about 1.8k LOC plus tests) was not in the working tree or in any commit. It existed only as dangling git objects (tree `fae309b2e7502028bb6b30f2b4ad9abc6ef43193`) that `git gc` could prune.
- Result: `npm ci` (strict peers), `build`, `typecheck` and CI all failed, and nothing could release a 0.2.1 of the published `gridmaster-react@0.2.0`.

## Decision

- The v2 tree is anchored at `refs/rescue/v2-tree-fae309b` (a ref, so it is safe from gc). Do not delete it.
- v1 is the shipping package: `packages/gridmaster-react/` (npm name `gridmaster-react`, version unchanged at 0.2.0 for now). Source, tests and demo were `git mv`ed from `legacy/v1/` to keep rename history.
- Root workspaces list only `packages/gridmaster-react`. `packages/core`, `packages/react` and `apps/playground` stay on disk untouched and unlisted ("parked").
- Root v2-only files (`vitest.config.ts`, `playwright.config.ts`, `tsconfig.json`, `tests/workspace.unit.test.ts`) moved to `parked/v2/`. Biome and CI ignore parked projects.
- `tests/integration.test.mjs` was restored from commit 3b00f0c; the suite count is 8.

## How to undo

1. Add the parked packages back to `workspaces` in the root `package.json` (for example `"packages/*", "apps/*"`) and `git mv` the files in `parked/v2/` back to the repo root (vitest/playwright/tsconfig; the test goes back to `tests/`).
2. Full v2 source: `git ls-tree -r refs/rescue/v2-tree-fae309b` to inspect, `git restore --source=refs/rescue/v2-tree-fae309b -- packages apps` to restore (the ref points directly at the recovered tree object, not a commit).
3. Restore the pre-decision v1 layout (v1 under `legacy/v1/`): `git mv packages/gridmaster-react/{src,tests,demo} legacy/v1/`.
4. Re-run `npm install` to refresh the lockfile.
